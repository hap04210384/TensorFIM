# TensorFIM U 盘一键验证包（v2.1 · 免安装版）

> 版本记录：v2.1（2026-09-26）双引擎同步了 ID 压缩修复（支持 webdocs 等宽稀疏命名空间数据，位图内存按幸存项数分配）；与本机 `anyfim_bmma\src` 当前源码逐字节一致，自测 accidents_x4@0.40 双引擎 PASS（762 项集逐项一致）。

## 给同事的一句话说明

> 插上 U 盘 → 双击 `RUN_ME.bat` → 然后别动电脑，等它自己跑完 → 看到 "DONE" 拔 U 盘还给我。**不需要安装任何软件**。
>
> 万一环境有问题，它会在开头一分钟内自己报错停下，不会白跑；时间紧就在 cmd 里跑 `RUN_ME.bat quick`（约 30 分钟），效果一样。

## 详细流程

1. **双击 `RUN_ME.bat`**（完整版 8 个配置，约 1.5–2 小时）。时间紧的话，在 cmd 里运行 `RUN_ME.bat quick`（快速版 3 个配置，约 30 分钟）。

2. **不需要装 CUDA、不需要装 Visual Studio**：包里带的是预编译好的程序（静态链接，覆盖 RTX 30/40/50 系、A100/H100/B 系列数据中心卡，并含 PTX 兜底）。只要电脑能正常用这块 NVIDIA 显卡（有驱动），就能跑。
   - 极少数情况下预编译程序无法启动（比如驱动太老），包会自动退回"现场编译"模式，那时才需要联网安装编译环境（屏幕会有指引，系统弹权限框点"是"）。

3. **跑的过程中不要动电脑**：不开浏览器、不玩游戏，最好锁屏放着。计时数据怕干扰。

4. 看到 `DONE. It is now safe to remove the USB drive.` 后拔盘。

## 批处理会自动做的事

1. 探测 GPU 型号和架构（太老的卡自动只跑基线引擎并注明），并保存显卡完整快照（驱动、时钟、功耗上限）
2. 对 8 个数据集配置逐一：双引擎各跑 3 次（含稀疏真实数据 kosarak 和生物医学数据 TCGA_BRCA）
3. **持续负载探针**（30 秒）：记录每秒的 tensor core 吞吐曲线，用于检测 RTX 5090D 等国行卡的"AI 算力锁"是否影响本负载
4. **峰值吞吐扫描**（几分钟）：8 种规模的 BMMA 微基准，测出这块卡 tensor core 的绝对性能（论文跨平台表用）
5. 挖掘结果与包内参考答案**逐项集比对**（一个都不能差，比对不上会明确写 FAIL，绝不会带病通过）
6. 生成 `REPORT.txt`（机器信息 + 每个配置的正确性 PASS/FAIL + 中位耗时）

## 带回来的东西

- `runs\` 文件夹——**每台跑过的电脑一个独立子文件夹**（名字含机器名 + GPU 型号 + 时间戳），互不覆盖；里面有 `REPORT.txt`（该机的正确性结论和耗时）、全部运行日志、以及 `sustain_probe.csv`（逐秒吞吐曲线）
- 同一个 U 盘可以在多台电脑上连续跑，数据自动分开存放

## 备注

- 建议 USB 3.0 以上接口（数据集 7 GB）
- exe 退出码为 1 是程序原有行为，不影响结果
- 本包不挑 GPU：任何 NVIDIA 卡（GTX 10 系到 RTX 50 系）都能跑；RTX 20 系及更老的卡只跑基线引擎
- 若看到 REPORT.txt 里出现 `MISSING` 或 `FAIL`，把 U 盘带回来即可，数据本身有诊断价值
