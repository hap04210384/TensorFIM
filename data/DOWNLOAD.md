# Datasets

## Included directly

| file | content | size |
|---|---|---|
| `small/mushrooms.txt` | FIMI mushrooms (8,415 txns) | 0.6 MB |
| `small/chess.txt` | FIMI chess (3,196 txns) | 0.3 MB |
| `small/connect.txt` | FIMI connect (67,556 txns) | 8.9 MB |
| `small/retail.txt` | FIMI retail (88,162 txns) | 4.0 MB |
| `small/T10I4D100K.txt` | FIMI synthetic T10 (100,000 txns) | 3.9 MB |
| `small/kosarak.dat` | kosarak click-stream (990,002 txns) | 31 MB |
| `small/accidents.txt` | FIMI accidents (340,183 txns) | 35 MB |
| `TCGA_BRCA_stripped.txt.gz` | TCGA-BRCA genomics, kernel items stripped (1,226 txns x 31,683 items) — gunzip before use | 46 MB |

All small datasets originate from the FIMI repository (https://fimi.uantwerpen.be/)
and kosarak from the same source; they are mirrored here for reviewer convenience.

## Generated by script

| file | how |
|---|---|
| `accidents_x4.txt` | `python data/make_replica.py data/small/accidents.txt 4 data/accidents_x4.txt` |
| `accidents_x8.txt` | `python data/make_replica.py data/small/accidents.txt 8 data/accidents_x8.txt` |
| `pumsb_x256.txt` | download `pumsb.dat` from https://fimi.uantwerpen.be/data/ then `python data/make_replica.py pumsb.dat 256 data/pumsb_x256.txt` (~4.3 GB) |

Replication keeps item ids unchanged, so supports scale exactly by the
replication factor (verified in the paper, Table III).

## Gold references

`gold_results/` holds the reference MFI outputs (`<dataset>-<threshold>=Results.txt`)
for all 13 paper configurations and the 13 threshold-sweep points. Every engine
run in `scripts/` is set-verified against these files; `scripts/verify_all.py`
re-checks everything on demand.
